  当前最需要处理的问题：

  用户反馈：
  “生图超过 2 分多钟会自动失败。”

  已完成诊断：开发服务器 HAR 显示 MHOO 的 `/v1/images/edits` 约 125 秒后返回 Cloudflare `HTTP 524`，响应服务器为 Cloudflare，CORS 预检正常。ImageX 没有 120 秒生图超时或自动取消逻辑。MHOO 已确认这是其上游问题，暂不作为 ImageX 可修复项。

  建议检查顺序：

  1. 搜索项目中是否存在固定超时：
     - setTimeout
     - AbortController
     - AbortSignal.timeout
     - Promise.race
     - timeout
     - REQUEST_TIMEOUT
     - 120000
     - 150000
     - 2 * 60
     - queue timeout
     - stale request
     - expiration

  2. 重点检查文件：
     - src/hooks/use-image-console.ts
     - src/lib/api.ts
     - src/lib/image-console.ts
     - 生成结果列表和请求队列相关组件
     - 任何封装 fetch 的工具文件

  3. 检查是否存在以下情况：
     - ImageX 主动在 120 秒左右调用 AbortController.abort()
     - 请求队列把运行时间过长的任务标记为失败
     - 前端 loading 状态有最大持续时间
     - 浏览器 fetch 本身被手动取消
     - 开发服务器或反向代理存在超时
     - 供应商 API 自己返回 408、504、524、5xx
     - 供应商长连接被 CORS、浏览器网络或代理中断
     - 供应商返回的是异步 task_id，但当前 ImageX 只支持同步响应

  4. 判断标准：
     - 如果浏览器 Network 中请求在约 120 秒时变成 canceled/AbortError，说明是 ImageX 或浏览器端主动取消。
     - 如果收到 408、504、524 或供应商自定义错误，优先判断是供应商或中间代理超时。
     - 如果请求一直 pending，但页面状态先变成失败，说明前端状态机可能有超时逻辑。
     - 如果供应商网站同样请求可以超过 2 分钟完成，而 ImageX 失败，则要重点检查 ImageX 的 fetch、AbortController、队列和
     响应解析。
     - 如果供应商网站也在约 2 分钟失败，则更可能是供应商或网络链路限制。

  5. 建议先做诊断，不要马上改代码：
     - 找到具体失败时间
     - 记录浏览器 Network 的请求状态、HTTP 状态和响应内容
     - 记录控制台错误名称
     - 区分 AbortError、TypeError: Failed to fetch、HTTP 错误和响应格式错误
     - 不要记录或输出 API Key、完整响应中的敏感内容

  本轮已完成的通用兼容能力：

  1. 供应商自定义认证
     - 每个 OpenAI 供应商可配置认证 Header 名称和 Key 前缀。
     - 默认仍为 `Authorization: Bearer <key>`；前缀可留空，例如 `x-api-key: <key>`。
     - 请求入队时冻结配置，切换供应商不会影响运行中的请求。

  2. 异步任务轮询
     - 可配置提交后任务 ID 路径、轮询 URL（支持 `{task_id}`）、状态路径、结果路径、错误路径。
     - 可配置成功/失败状态值、轮询间隔和最大次数。
     - 支持标准图片响应、图片 URL、Base64 和嵌套结果；轮询失败或超时不会重复提交任务。
     - 默认关闭，未知供应商不会改变原有同步行为。

  3. 错误分类
     - `524` 明确提示供应商网关等待上游超时，提醒用户先确认扣费状态再重试。
     - `408`、`504`、`429` 增加面向用户的解释。

  4. 回归验证
     - 自定义 Header、异步轮询、524 分类均有测试覆盖。
     - 当前验证：8 个测试文件、97 个用例通过；typecheck 和 production build 通过。
     - 套图模板导入/导出已完成：模板只包含商品字段和槽位模板，不包含图片、API Key、任务结果或本地路径。
     - 套图配置区已显示当前批次的启用槽位进度摘要。
     - localStorage 设置增加上一份本地备份；当前 JSON 损坏时可恢复上一份配置，备份不会上传。
